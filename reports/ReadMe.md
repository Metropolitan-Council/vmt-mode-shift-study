Contains several reports and presentations developed over the course of the project.  The most relevant aspects are absorbed into the appendix of the final report, but remain here for editing purposes.  The final report is available in the shared drive at:

`VMT Reduction Mode Shift Final Report.docx`

Most of the additional reports here are in [Quarto](https://quarto.org/) format.  Quarto can mix code and text, similar like a jupyter notebook, and will auto-update figures and other outputs with new data.  It will render the outputs to a html, PDF, Word, jupyter notebook, or other formats.  To render, you will need to install Quarto, then run a command similar to:

`quarto render <filename>.qmd --to pdf`

or 

`quarto render <filename>.ipynb --to html`

You can change both what it renders to, and the type of file you are rendering.
