In the car speed scenario, we cap StreetLight speeds with [NACTO recommendations](https://nacto.org/publication/city-limits/the-right-speed-limits/). The recommendations require some speed studies, so we simplify further, using the following speed table

|                     | Urban    | Suburban | Rural |
|---------------------|----------|----------|-------|
| Shared street/alley | 10 mph   |  10      | 10    |
| Minor streets       | 20       |  20      | 20    |
| Major streets       | 25       |  35      | 35    |
| Freeways            | 55       |  55      | 65    |

We map OpenStreetMap `highway` tags to street types using `highway_types.csv` file; the template for this file (listing all highway tags) is generated by the Julia script `extract_highway_tags.jl`
